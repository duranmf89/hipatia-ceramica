# Hipatia Cerámica

App de clases y tienda para Hipatia, estudio de cerámica en Barrio Urca, Córdoba.

**Estado:** maqueta navegable (Fase 0). Los datos viven solo en el navegador de cada persona; todavía no hay cuentas reales, pagos ni mensajes de WhatsApp.

Para instalarla en el celular: abrir el enlace de GitHub Pages y elegir "Agregar a pantalla de inicio".
